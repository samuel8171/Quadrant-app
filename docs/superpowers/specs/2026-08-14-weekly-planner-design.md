# 周计划表模块设计文档

- 日期：2026-08-14
- 状态：已获用户确认（含第 4 点修改）
- 技术栈：Electron + React + TypeScript + Zustand + Vitest

## 1. 目标与范围

在现有"璞石界限"应用（目标、四象限、周计划、周日复盘四个页面）中，把周计划页从占位页替换为完整模块：

1. 周视图：7 天总览缩略图，自适应窗口大小，仅查看；表头可点击进入单日视图；抬头显示周日期范围与"坚持第 n 周"。
2. 单日视图：左侧纵向时间轴（仅上下滚动、不可缩放），右侧全局事件预设面板，支持创建/修改/删除、拖拽与整点吸附。

本阶段不做四象限事件的实时联动，但为联动预留数据字段；联动的具体规则后续单独设计。

## 2. 数据模型

AppData 版本从 1 升到 2，`dataCodec.parseData` 兼容 v1/v2：v1 数据自动补充空的周计划字段并升级为 v2，旧数据无损；其他版本拒绝。`defaultData()` 返回 v2 默认值。

```ts
export type Quadrant = 1 | 2 | 3 | 4 // 沿用现有定义

export const WEEK_COLORS = [
  '#8AB4F8', // 晴空浅蓝
  '#8CD9C1', // 薄荷青绿
  '#F8B18C', // 蜜桃浅橙
  '#B4A7E6', // 薰衣草浅紫
  '#E8A0A0', // 柔豆沙红
  '#DBC8A8', // 暖卡其
  '#A9C49C', // 灰豆绿
  '#C2C8D0'  // 浅云灰
] as const

export interface WeekPreset {
  id: string
  title: string
  color: string        // WEEK_COLORS 之一
  quadrant: Quadrant   // 对应四象限 1~4
  durationMin: number  // 时长（分钟），5 的倍数，范围 5~600
  remark: string
  createdAt: string
}

export interface WeekEvent {
  id: string
  date: string         // 'YYYY-MM-DD'（本地日期，随周滚动不丢失）
  title: string
  color: string
  quadrant: Quadrant
  startMin: number     // 距 0:00 的分钟数，范围 420~1440
  endMin: number       // startMin < endMin <= 1440，时长 <= 600
  remark: string
  presetId?: string    // 由预设拖入时记录来源，供后续联动
  createdAt: string
}

export interface AppData {
  version: 2
  goals: Goal[]
  events: QuadrantEvent[]
  weekPresets: WeekPreset[]
  weekEvents: WeekEvent[]
  weekCounterOffset: number  // "坚持第 n 周"的手动偏移
}
```

事件块不存像素坐标，只存分钟时间，坐标由渲染层按规则换算，保证窗口缩放后位置依然正确。

## 3. 周计数器规则

- 锚点：2026-08-10（周一）为第 1 周。
- `baseWeek = 距锚点的整周数 + 1`（当前周 2026-08-10 ~ 08-16 即第 1 周）。
- 显示值 `n = baseWeek + weekCounterOffset`，下限 1；跨周时 baseWeek 自动 +1。
- 手动修改 n：写入 `weekCounterOffset = n - baseWeek`，立即持久化。

## 4. 周视图（主页面）

- 抬头左侧："8月10日-8月16日"（随浏览周变化），右侧小字"坚持第 n 周"（点击变数字输入框，回车/失焦保存）。
- 表头 7 列：周一~周日（含日期数字，如"周一 8/10"），整列表头可点击进入该日单日视图。
- 左侧时间轴：7:00（原点）~ 24:00，每小时一个刻度，共 17 格；刻度文字在表格外左侧，从每个整点向右延伸灰色半透明横线贯穿 7 列。
- 网格自适应可用高度：`hourPx = clamp((可用高 - 表头高) / 17, 28, 64)`，窗口过小时网格内部纵向滚动。
- 事件块：上边缘 = 开始时间、高度 = 时长（按 hourPx 换算），随窗口同步缩放；仅查看、不可交互。
- 顶部提供 ‹ › 切换上一周/下一周；默认进入当前周。
- 事件块样式同单日视图（见第 7 节），高度不足 18px 时只显示色块不显示文字。

## 5. 单日视图

- 抬头："周五 · 8月14日"（周几 + 日期）+ 返回按钮 + 上一日/下一日箭头；右侧"添加"按钮。
- 布局：左侧时间轴（1 小时 = 48px，总高 816px，纵向滚动、不可缩放）+ 右侧事件预设面板（固定宽约 280px）。
- 时间轴：7:00~24:00 每小时刻度与横向发丝网格线；当日视图显示红色"当前时间"指示线（在 7:00~24:00 内时）。
- 事件块渲染：`top = (startMin - 420) / 60 * 48`，`height = (endMin - startMin) / 60 * 48 - 2`。
- 空白处双击：以点击处最近整点作为开始时间打开"新建事件"菜单；顶部"添加"按钮打开同一菜单，开始时间默认取当前时刻向上取整到最近整点（当前时刻不在 7:00~24:00 时取 7:00）。

## 6. 菜单栏（新建/修改弹窗）

共用同一个弹窗，按来源区分两种时间控件：

- 标题（文本输入）
- 颜色：8 个圆形色块单选（WEEK_COLORS，选中显示描边/勾选）
- 重要紧急程度：4 个选项，每个为"四象限颜色圆 + 类型文字"（重要紧急 #FF8C00 / 重要不紧急 #FFA500 / 不重要不紧急 #008B8B / 不重要紧急 #483D8B）
- 时间：
  - 预设：快捷时长 0.5 / 1 / 1.5 / 2 / 2.5 / 3 / 4 小时 + "自定义"（小时 0~10 + 分钟 5 分钟步进）；总时长 5 分钟 ~ 10 小时（600 分钟），去掉 6、8 小时快捷项
  - 时间轴事件：开始时间（7:00~23:55，5 分钟步进）+ 截止时间（7:05~24:00，5 分钟步进），校验 开始 < 截止 且时长 <= 10 小时
- 备注（多行文本）
- 按钮：取消 / 保存；修改模式额外提供"删除"（删除需确认）

## 7. 视觉规范（深色苹果日历）

沿用现有深色主题变量，参考苹果日历结构语言：

- 背景 `#0F1115`，面板 `#1A1D23`，卡片 `#1F242C`，发丝线 `#2C3036`。
- 小时横线：`rgba(255,255,255,0.06)` 1px；刻度文字 `#B0B5C0` 12px。
- 事件块：填充色 = 事件颜色 18% 透明度，边框 = 同色 55% 透明度 1px，左侧 3px 实心色条，圆角 6px；标题白色 13px，时间范围与四象限类型为白色 75% 透明度 11px；内部含小圆点（四象限颜色）+ 类型文字。
- 当前时间线：`#E5484D` 1px，左端小圆点。
- 交互强调统一用应用强调蓝 `#4DA3FF`。
- 预设卡片：背景 = 事件颜色 12% 透明度，边框 = 同色 45% 透明度；高度与时长成正比：`clamp(56, 56 + hours * 24, 260)`；hover 显示编辑/删除图标按钮。
- 弹窗圆角色块直径 24px，选中项带 2px 强调蓝描边。

## 8. 交互规则

- 预设拖到左侧时间轴：复制生成当天事件（预设不变，事件记录 presetId）；落下后开始时间吸附最近整点；若时长会超出 24:00，开始时间回收到 `floor((1440 - durationMin) / 60) * 60`；结束 = 开始 + 时长。
- 时间轴事件拖动：仅上下移动，松手开始时间吸附最近整点（时长不变），并夹取到 [420, 1440 - 时长] 内；不能拖回右侧预设面板；拖动后事件时间信息同步更新。
- 事件右键菜单：修改信息 / 删除（删除需确认）。
- 预设卡片：hover 显示编辑/删除按钮；创建后同样可修改、删除。
- 直接创建的时间轴事件只出现在时间轴，不进入右侧预设列表。

## 10. 修订记录（2026-08-14）

### 10.1 四象限联动

- `WeekEvent` 增加 `showInQuadrant`（默认 false）与 `quadrantEventId`。
- 单日时间轴事件弹窗新增"在四象限中呈现"开关（仅时间轴事件；预设不提供）。
- 开启时：在对应象限自动寻找不与既有事件重叠的位置创建同信息事件（标题、备注、象限一致），并记录联动 id；单象限最多 30 个事件，超出时提示"该象限事件已达30个，无法继续添加"并阻止保存。
- 修改事件：标题/备注/象限变化同步到已联动事件；象限改变时自动换象限重新排位。关闭开关或删除事件时，联动事件一并删除。

### 10.2 显示修正

- 周视图：隐藏 7:00 标签；事件块仅显示标题（字号约 10.5px）。
- 单日视图：时间长度小于 45 分钟的事件块仅显示标题；预设卡片小于 45 分钟时隐藏重要紧急程度，仅显示标题与时间长度。
- 单日时间轴顶部与底部各增加 10px 留白，7:00 与 24:00 标签及其对应线完整可见；24:00 边界线横贯整条时间轴。
