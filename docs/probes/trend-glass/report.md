视口 375×667（短屏；只有这一档趋势卡才落在 dock 后面）。
保留率 = std(材质开)/std(材质关)，采样盒取「目标 ∩ 材质板」。≤0.2 判活。
线的信号 = (B − R) 的 97.5 分位（条纹是中性色，对这个差值零贡献）。
sharpRatio = 峰值(开)/峰值(关)：线被糊过则显著小于 1（实测糊 0.23 / 未糊 1.00）。
